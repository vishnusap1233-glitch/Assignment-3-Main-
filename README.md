# Assignment-3-Main-
Assignment-3;(interactive website main)
I designed and built this responsive one-page portfolio website using advanced CSS techniques.

✨ Features

• Layouts: Flexbox for headers/hero alignment and CSS Grid for organized card sections.
• Responsiveness: Mobile-first approach using relative units (rem, vw, vh) and media queries.
• Interactivity: Smooth hover effects, element transitions, and keyframe animations for text.
• Structure: Clean, semantic sections containing an About, Skills, Projects, and Contact form.
